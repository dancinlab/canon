# ☀️ FUSION — "핵융합로 설계점을 6관문으로 거르는 계산 파이프라인"

> 쉽게 읽는 한 장 요약 (easy 버전). SSOT: `domains/FUSION/` (F1~F6 게이트).
> "설계가 타당하냐"를 계산으로 닫는 것이며, "Q>1을 실제 달성했다"는 주장이 아닙니다(정직·d2).

## 한 줄로

- **하는 일**: 컴팩트 자기가둠 핵융합로의 **설계점(온도·밀도·자석·블랭킷)이 물리적으로 말이 되는지**를 6개 관문으로 순서대로 걸러 랭크·검증.
- **별칭**: "핵융합 설계 6관문 체"
- **비유**: 정수기 6단 필터 — 물(후보 설계)이 반응성→로손→평형→안정성→자석→연료자급 필터를 차례로 통과해야 "마실 수 있는 물(타당한 설계)".

```
[ 설계 후보 ] ─▶ 반응성 ─▶ Lawson/Q ─▶ 평형 ─▶ MHD안정 ─▶ HTS자석 ─▶ TBR연료자급 ─▶ ✅ 타당
                 (얼마나 잘 타나)        (가둘 수 있나)        (자석 되나)   (연료 자급되나)
```

---

## 왜 중요한가 — 핵융합은 "설계점"부터 막힌다

핵융합 발전은 **태양처럼 가벼운 핵을 융합**해 에너지를 냅니다. 문제는 "되긴 되나"가 아니라
**어떤 설계점(온도·밀도·크기·자석세기)이 동시에 물리 조건을 다 만족하나**입니다. 한 조건을 맞추면
다른 게 깨지죠(예: 더 뜨겁게 → 자석·안정성 부담↑). 그래서 **여러 물리를 한 번에 통과하는 설계점**을
찾는 게 핵심이고, FUSION은 그걸 비싼 실험 전에 **계산으로 미리 거릅니다**.

---

## 일반인에게 뭐가 바뀌나 — 핵융합 발전이 현실이 되면

핵융합은 "태양을 병에 담는" 발전 방식입니다. 만약 이 설계가 실제 발전소로 이어지면 보통 사람의
일상은 아래처럼 바뀝니다. (단, 본 캠페인은 **설계 타당성**을 계산으로 닫은 것이고, 실제 발전소는
실험로의 몫 — 정직.)

```
핵융합 발전 현실화 →
├─ 💡 전기요금   : 연료가 바닷물 속 중수소 → 사실상 무한·저가
├─ 🌍 기후       : 발전 중 탄소배출 0 (온실가스 없는 기저전력)
├─ ☢️ 폐기물     : 핵분열(원전)과 달리 장수명 고준위 폐기물 거의 없음
├─ 🔌 안정성     : 날씨 무관 24시간 (태양광·풍력의 간헐성 없음)
├─ 🤖 AI/데이터  : 폭증하는 전력 수요(데이터센터)를 청정하게 감당
└─ 🛢️ 에너지안보 : 연료 수입 의존 탈피 (바닷물은 어디에나)
```

| 지금(화석·원전) | 핵융합이 오면 |
|---|---|
| 연료=석유/가스/우라늄(수입·고갈) | 연료=중수소(바닷물)·삼중수소(스스로 생성) |
| 탄소배출 or 고준위 폐기물 | 탄소 0 · 장수명 폐기물 거의 0 |
| 태양광/풍력=날씨 따라 출렁 | 24시간 일정한 기저전력 |
| 전기요금 변동·상승 | 장기적으로 싸고 안정 |

> 비유: 지금은 장작·기름을 계속 사다 때는 난로라면, 핵융합은 **바닷물 한 컵으로 도시를 데우는 난로**.
> 단, 아직 "난로 설계도가 물리적으로 맞다"까지 온 단계이고, "실제로 불붙어 흑자(Q>1)"는 실험로가 증명할 몫입니다.

## 무엇을 계산으로 닫았나 — 6관문

| 관문 | 무엇을 보나 | 결과 |
|---|---|---|
| 🔥 F1/F2 반응성·Lawson | 얼마나 잘 타고, 가둠 조건(Q) 충족? | 🔵 닫힌식 (Bosch-Hale ⟨σv⟩ + Q, 9 검증 Δ=0.0) |
| 🧲 F3 평형 | 플라스마가 자기장 안에 안정히 앉나 | 🟢 실측급(FreeGS: Ip 200kA·q95≈10·κ 1.36) |
| 🌀 F4 MHD | 거대 불안정으로 안 터지나 | 게이트 통과 |
| 🧲 F5 자석장 | HTS 코일이 목표 자기장을 만드나 | 🟢 FEM Δ=−0.064% vs 1.4827T |
| ♻️ F6 TBR(연료자급) | 삼중수소 연료를 스스로 만드나 | 🟢 OpenMC TBR=1.32 (DEMO급 자급) |

> 🎯 핵심: **연료 자급(TBR>1)이 계산상 확인됨** — TBR=1.32는 융합로가 태우는 삼중수소를
> 블랭킷에서 스스로 1.32배 만들어낸다는 뜻(자급 가능). 이게 안 되면 핵융합은 연료가 말라 멈춥니다.

```
전 (막연한 "핵융합 됨")         후 (FUSION 6관문 계산)
─────────────────             ─────────────────
 ▢ "언젠가 된다"          →    ▢ 설계점이 6물리 동시충족인지
 ▢ 비싼 실험부터              계산으로 랭크·검증(비용 0~소액)
                              ▢ 닫힌식 9개 Δ=0.0·TBR 1.32
```

- **🔵 keystone 닫힘**: 반응성·Lawson을 닫힌 수식으로(검증 아톰 Δ=0.0).

- **정직(d2)**: 이건 **설계 타당성** 검증이지 **Q>1 실증**이 아닙니다 — 실제 점화는 실험로의 몫.
